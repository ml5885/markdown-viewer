## Markdown Viewer

This is a simple Chrome extension that renders markdown files when you open them in Chrome. It has several features:

- A live table of contents on the side (specifically, it's a list of headings in the file)
- A dropdown to select the font (uses the fonts on your computer)
- A light/dark mode toggle
- A toggle to view the raw markdown
- A "no distractions" mode that hides the aforementioned features
  - Note: the button for this is in the bottom right corner and is hidden until you hover over it
- LaTeX expressions are rendered with MathJax

To use this extension, clone this repository, then follow the instructions [here](https://superuser.com/questions/247651/how-does-one-install-an-extension-for-chrome-browser-from-the-local-file-system).
